# Infinity Foundation website

A responsive static website for Infinity Foundation, built with HTML, CSS, and JavaScript. The site includes the home page, About, What We Do, Health, Education, Programs, and Contact pages, plus the campaign carousel and book distribution gallery.

## Preview locally

Open `index.html` in a browser. No build tools or package installation are required.

## Update the live website

The site is connected to Cloudflare Pages. After changes are pushed to the `main` branch of the connected GitHub repository, Cloudflare Pages automatically publishes them to the foundation's `pages.dev` address.

The website is informational and does not process donations or collect personal information. Contact links open email or Instagram.
