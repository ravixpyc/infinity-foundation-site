# Infinity Foundation website

A responsive static website built with HTML, CSS, and JavaScript. It includes the campaign image carousel, Marathi mission statement, founder section, book distribution photo gallery, contact information, and parchment and Warli artwork.

## Preview locally

Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages

The workflow in `.github/workflows/deploy.yml` publishes the site after each push to the `main` branch. In the GitHub repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. After the first successful deployment, the Actions run will show the live URL.

GitHub Pages is free for public repositories on GitHub Free. A public repository also makes the website source and image files public. The site is informational and does not collect payments or personal information.
